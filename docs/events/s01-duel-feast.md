# S01 — Пир и кровь (дуэль на пиру)

| Поле | Значение |
|------|----------|
| Масштаб | **S** |
| Тип | Пир / двор + дуэль |
| Длительность | 45–90 мин |
| Ведёт | Игроки (штаб только если просят арену/судью) |
| Онлайн | 2–8 |

## Зачем

Дать домам повод для интриги и публичного выяснения отношений **без** осады claim. После пира в хронике появляется оскорбление, долг чести или брак — топливо на недели.

## Крючок (объявление)

> В зале [Город] дом [X] зовёт соседей на пир. Вина хватит на всех. Оскорбления — на совесть хозяина. Кто явится с голой сталью без вызова — враг дома.

## Подготовка (15 мин)

1. Хозяин назначает зал (claim или нейтральная постройка).
2. Правила в Discord до старта:
   - пир = мир в зале, пока не объявлена дуэль;
   - дуэль 1v1 на арене рядом; до первой крови / до смерти (выбор хозяина);
   - зрители не вмешиваются.
3. Штаб (опционально): временный мир в зале голосом; судья с таймером.

## Ход

1. **Сбор** (10 мин) — гости, подарки (ресурсы / трофеи), тосты.
2. **Интрига** (20–40 мин) — сделки шёпотом, слухи, вызов на дуэль.
3. **Дуэль** (если была) — на арене; итог фиксирует хозяин или судья.
4. **Финал** — хозяин объявляет: мир / кровная месть отложена / помолвка / изгнание гостя.

## Чем заканчивается

Обязательная запись в `#хроника` (3–5 строк): кто пришёл, что постановили, есть ли долг чести.

**Не выдавать:** админ-лут, залежи, права на claim.

## Вариации

- Свадебный пир вместо обычного.
- «Суд чести» без боя: спор решают свидетели и клятва.
- Пир во время перемирия двух воюющих домов (ставки выше).
