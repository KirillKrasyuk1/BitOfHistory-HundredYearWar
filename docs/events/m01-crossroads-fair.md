# M01 — Ярмарка на перепутье

| Поле | Значение |
|------|----------|
| Масштаб | **M** |
| Тип | Торговля + RP |
| Длительность | 1 вечер (2–3 часа) |
| Ведёт | Штаб (площадка) + игроки (лавки) |
| Онлайн | 8–20 |

## Зачем

Свести дома без обязательной войны. Показать региональную экономику: у кого зерно, у кого железо, у кого серебро. Заключить сделки и маршруты, которые живут после ярмарки.

## Крючок

> На перепутье у [координаты / пост] объявлена ярмарка. Три дня пути — один день торга. Дома, держащие торговые посты, получают почётное место. Оружие в ножнах, пока не сорван мир ярмарки.

## Подготовка (день до)

1. Штаб выбирает **нейтральную** площадку (не столица одного дома) или договаривается с хозяином claim о правилах.
2. Ставит / чинит **Trade Post**; по желанию временный `route` с дешёвым тарифом «ярмарочный день».
3. Discord: слоты лавок (кто что везёт), правило мира, что считается грабежом.
4. Награда штаба (скромная): 1 малый `deposit` по итогу самому активному торговцу **или** ничего материального — только хроника и статус.

## Ход

| Фаза | Время | Содержание |
|------|-------|------------|
| Съезд | 30 мин | Расстановка лавок, вывески, объявление цен |
| Торг | 60–90 мин | Сделки, найм караванщиков, брачные/союзные разговоры |
| Испытание (опц.) | 20 мин | Стрельба / скачки — без потери claim |
| Закрытие | 15 мин | Глашатай: итоги, подписанные договоры, дата следующей ярмарки |

## Правила мира

- В радиусе ярмарки: нет осады, нет убийств.
- Кража из сундука лавки = объявление войны хозяину лавки + бан на ярмарку.
- Срыв мира одним домом → ярмарка закрывается; виновник в хронике.

## Чем заканчивается

- Список сделок в `#хроника`.
- 0–2 новых постоянных `route` между постами (если игроки попросили и штаб ок).
- Слух для M02: «богатый обоз ушёл на восток…».

## Связь с экономикой

См. `docs/ECONOMY_GOT.md`: регионы с избытком/дефицитом должны быть **видны** на ярмарке (цены разные). Если все тащат одно и то же — ярмарка мёртвая; поправить залежи до следующей.
