# M03 — Суд дома

| Поле | Значение |
|------|----------|
| Масштаб | **M** |
| Тип | Суд / политика |
| Длительность | 60–90 мин |
| Ведёт | Игроки (лорд-судья); штаб — секретарь хроники |
| Онлайн | 6–15 |

## Зачем

Закрыть конфликт без вайпа и без вечного вой в чате. Придать вес клятвам, свидетелям, штрафам ресурсами и изгнанию.

## Когда запускать

После пира с кровью, сорванной ярмарки, рейда «под чужим флагом», убийства гостя, нарушения перемирия. **Не** вместо осады за территорию — суд не отбирает claim сам по себе (может обязать добровольно уступить или выплатить).

## Крючок

> Лорд [Z] созывает суд в [город] по делу [кратко]. Стороны: истец / ответчик. Свидетелям явиться к [время]. Приговор будет записан в хронику и считается законом между подписавшими домами.

## Подготовка

1. Истец пишет обвинение (10 строк max) в Discord.
2. Ответчик — короткий ответ.
3. Судья (нейтральный лорд или выбранный советом) утверждает правила:
   - оружие сдано у входа;
   - говорить только по вызову;
   - ложная клятва = штраф / изгнание.
4. Штаб готовит шаблон приговора.

## Ход

1. Чтение обвинения.
2. Речь истца → ответчика → свидетелей (таймер 3–5 мин на речь).
3. Совещание судьи (5–10 мин, можно с советниками).
4. Приговор вслух + пост в `#хроника`.

## Возможные приговоры (меню)

| Приговор | Эффект в мире |
|----------|----------------|
| Штраф | Передача N ресурсов / голов скота до срока |
| Вира | Компенсация семье / дому |
| Изгнание | Персонаж не входит в claim дома N дней |
| Клятва мира | Перемирие N дней; нарушение → авто-война |
| Ордалия | Дуэль вместо приговора (см. S01) |
| Передача дела | На L01 Великий совет |

Штаб **не** банит за игровой приговор, если не было читерства. Игровой изгнанник ≠ Discord-бан.

## Чем заканчивается

Один пост-приговор. Если сторона не исполняет — это уже повод к войне или эмбарго, не к рероллу суда тем же вечером.
