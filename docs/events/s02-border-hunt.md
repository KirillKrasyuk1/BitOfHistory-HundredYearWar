# S02 — Охота на границе

| Поле | Значение |
|------|----------|
| Масштаб | **S** |
| Тип | Охота / патруль / PvE-lite |
| Длительность | 40–70 мин |
| Ведёт | Игроки одного дома или союз; штаб может подселить мобов |
| Онлайн | 3–8 |

## Зачем

Совместный выезд без политики «на весь сервер». Укрепляет отряд, даёт повод помериться с соседом или наткнуться на чужой патруль.

## Крючок

> С северной кромки [биом] снова тащат скот / слышен вой. Дом [X] собирает охотников у ворот на закате. Добыча — тому, кто добьёт; шкуры — в казну дома.

## Подготовка

1. Точка сбора у claim; маршрут 200–400 блоков в дикую зону (не в чужой claim без объявления войны).
2. Штаб (опционально): 1 волна HYW bandits или IaF-мелких мобов в конце маршрута.
3. Правила: PvP off между союзниками; чужие игроки на маршруте — переговоры или бой по желанию сторон.

## Ход

1. Сбор и назначение капитана охоты.
2. Проход по маршруту (добыча, разведка жил/биома).
3. Кульминация: засада мобов **или** встреча чужого патруля.
4. Возврат; дележка; слух в Discord («на границе видели знамёна Y»).

## Чем заканчивается

- Трофеи в казну / личный лут по договору дома.
- Опционально: штаб ставит слабый слух для M02 («на этом тракте небезопасно»).

**Не делать:** выдачу драконьего яйца или admin deposit с охоты S-масштаба.
