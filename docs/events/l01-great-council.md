# L01 — Великий совет

| Поле | Значение |
|------|----------|
| Масштаб | **L** |
| Тип | Совет / политика на весь сервер |
| Длительность | Анонс за 5–7 дней; заседание 2–3 часа |
| Ведёт | Штаб (процедура) + лорды (голос) |
| Онлайн | Желательно большинство активных домов |

## Зачем

Редкий момент, когда **все** дома в одном зале. Зафиксировать границы, торговые законы, перемирия, иногда — выбрать «сюзерена» или признать нейтральную столицу. После совета сезон получает рамку, которую игроки сами наполняют войной и сделками.

## Крючок

> Зима не ждёт. Дома [список] созываются на Великий совет в [нейтральное место]. Голос имеет глава фракции Recruits или его посланник с печатью. Без совета тракты останутся без закона, а кровь — без цены.

## Повестка (шаблон — править под сервер)

1. Признание существующих claim и спорных границ.
2. Правила войны: когда можно осаждать; защита гостей; ярмарочный мир.
3. Торговля: базовый тариф, эмбарго, эскорт караванов.
4. (Опц.) Избрание или отказ от сюзерена / хранителя столицы.
5. (Опц.) Общая угроза (подводка к L02 / XL01).

## Подготовка

1. Штаб публикует дату, координаты, повестку, кворум (например: ⅔ объявленных домов).
2. Каждый дом присылает делегата.
3. Площадка нейтральна; оружие в ножнах; убийство на совете = изгой сервера по правилам RP + возможный игровой бан по уставу.
4. Голосование: 1 дом = 1 голос (или взвешенно по числу claim — решить **до** совета и не менять в зале).

## Ход

1. Открытие, проверка полномочий.
2. Каждый пункт повестки: речь за / против (таймер) → голосование → запись.
3. Перерыв на кулуары (20 мин) — сделки и угрозы.
4. Закрытие: чтение «Актов совета»; подпись лордов эмодзи/реакцией в Discord.

## Чем заканчивается

- Документ **Акты Великого совета** в `#хроника` (и копия в `docs/chronicle/` при желании).
- Штаб включает/выключает механики под акты: тарифы, временный мир на ярмарках, запрет осады N дней если так решили.
- **Не** выдавать админ-оружие «королю». Власть = признание игроков + контроль столицы/маршрутов.

## Если кворума нет

Совет переносится один раз. Второй провал → «эпоха без закона» — штаб запускает M02/давление мира без общих правил (жёстче, но честно).
