# L02 — Право на дракона

| Поле | Значение |
|------|----------|
| Масштаб | **L** |
| Тип | Чудо / конфликт за артефакт |
| Длительность | 5–10 дней от слуха до развязки |
| Ведёт | Штаб (спавн/охрана зоны) + игроки (гонка и война) |
| Онлайн | Весь актив |

## Зачем

Один сильный фэнтези-крючок на сезон без превращения сервера в «кто первый забрал яйцо — тот Бог». Дракон/яйцо — **ставка политики**, а не личный имбовый питомец из сундука.

## Крючок (день 0)

> Пастухи с [биом] клянутся: в расселине светится камень, «как уголь с сердцем». Учёные домов спорят — яйцо или пустая скала. Кто первым закрепит место claim’ом и удержит его — решит судьбу огня в этом веке.

## Правила ставки (зафиксировать в анонсе)

1. Штаб отмечает **зону находки** (координаты + радиус). Первые 48 часов зона может быть временно без claim (или с NPC-охраной) — окно гонки.
2. После захвата claim обычные правила осады 5:1.
3. Яйцо/дракон **не** выдаётся в инвентарь случайному игроку админом. Варианты финала (выбрать один до старта):
   - **A.** Победивший дом получает яйцо предметно + жёсткий риск (IaF механика); штаб логирует.
   - **B.** Дракон остаётся «в мире» у логова; дом-владелец claim кормит/контролирует доступ; убийство дракона = потеря ставки.
   - **C.** Яйцо уничтожено/украдено третьей силой → переход в XL или новый слух.
4. Запрет: креатив-выдача mature dragon союзнику штаба вне правил.

## Фазы

| День | Фаза |
|------|------|
| 0 | Слух + координаты области (не точки) |
| 1–2 | Разведка, стычки в дикой зоне, союзы |
| 2–4 | Первая закрепка claim; осады; дипломатия |
| 5–7 | Стабилизация или смена владельца |
| Финал | Штаб подтверждает итог в хронике; при режиме A/B выдаёт/фиксирует дракона по правилам |

## Чем заканчивается

- Новый баланс сил: дом с огнём становится целью эмбарго и коалиций (это желаемо).
- Торговые дома могут нажиться на осадах (поставки железа/еды).
- Хроника: «Эра дракона началась под знаменем X» или «Яйцо разбито / украдено».

## Связь с экономикой

Рядом с логовым биомом уместен admin `deposit` (серебро/гемы) — но **не** DRAGONSTEEL в первый же день. Dragonsteel остаётся редким (см. ECONOMY_GOT).
