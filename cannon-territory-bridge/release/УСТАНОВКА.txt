# Cannon Territory Bridge 1.0.12 — установка
=========================================

Вербовка HYW только на своём клейме, только с отрядом. Краш 0.7.1 уже исправлен.

1. Скачай:
https://raw.githubusercontent.com/KirillKrasyuk1/BitOfHistory-HundredYearWar/cursor/cannon-territory-bridge-5fac/cannon-territory-bridge/release/cannon_territory_bridge-1.0.12.jar

2. CurseForge → Cannon → **mods**

3. Удали **ВСЕ** `cannon_territory_bridge-1.0.x.jar`

4. Положи `cannon_territory_bridge-1.0.12.jar`

5. Запусти — в логе:
   `Cannon Territory Bridge loaded`
   `[CTB-MOBILIZE] config requireOwnClaim=true requireSquad=true allowCreativeBypass=false`

## Что в 1.0.12

- Вербовка перехватывается в `RecruitmentOrderManager.createOrder` (настоящий найм HYW 0.7.1)
- Посох завоевателя не открывает меню вне своего клейма
- Креатив больше **не обходит** ограничения
- Красные сообщения: нет клейма / нет отряда / не на своей территории

В логе: `cannon_territory_bridge 1.0.12`
