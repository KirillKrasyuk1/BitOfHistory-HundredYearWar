# Cannon regional resources datapack
# Requires: Custom Ore Veins and/or ore-veins, Restrictive Farming, Better Caravans (optional)

See docs/ECONOMY_GOT.md for full integration guide.

Install: copy this folder to `saves/<world>/datapacks/` and run `/reload`.

Admin deposits (Casterly Rock gold, etc.) use `/cannoneconomy deposit add` from cannon-economy mod.
